Hyperstor

A sharded, distributed storage system in Rust, built for glidex nodes and usable without them. Replicated pools on its own io_uring engine, with block volumes, GPU-direct storage, S3 and a filesystem to come on the same object layer.

Quick start Documentation Status GitHub 
git clone https://github.com/CMKL-APEX/hyperstor.git && cd hyperstor
cargo build --release

Today

Replicated pools

Two or three copies of every chunk, placed across devices, hosts or racks. A write returns once every copy has it.

Its own engine

Pure Rust on io_uring, one thread per device, checksums on every 4 KiB block, crash recovery tested against a model.

Failure handling

Failed nodes detected by heartbeats, writes that go on with fewer copies, recovery of only what a returning node missed, scrub that repairs damaged copies, and leases that fence cut-off nodes.
