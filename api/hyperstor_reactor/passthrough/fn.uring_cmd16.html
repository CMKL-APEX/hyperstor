pub async unsafe fn uring_cmd16(fd: RawFd, cmd_op: u32, cmd: [u8; 16]) -> i32
Expand description

Sends command cmd_op with the 16 bytes cmd to the driver behind fd, from this reactor’s thread; resolves to the completion’s result.

§Safety

fd must stay open until the command completes, and any memory the command names (a buffer address in cmd) must stay valid until then, even if this future is dropped first: the kernel may still use it.
