pub fn set_spin_adaptive(on: bool)
Expand description

Makes set_spin’s window a ceiling the reactor on this thread adapts under, as KVM’s halt polling does: after an idle stretch longer than the window but within the ceiling (a longer window would have caught it) the window doubles, from SPIN_GROW_START; after one longer than the ceiling (no window would have) it halves, to zero under the start. Off by default.
