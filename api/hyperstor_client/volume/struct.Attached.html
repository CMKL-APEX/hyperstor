hyperstor_client::volume

Struct Attached 

Source 
pub struct Attached { /* private fields */ }
Expand description

A volume attached through a Client: it holds the volume’s rw lease (06-metadata.md §9), which the client renews every second (D75), and does I/O within the volume. Once the lease is lost (taken over, its identity fenced, or this client blocklisted), I/O fails with ClientError::LeaseLost. Dropped without Attached::detach, its renewals stop: the lease runs out, and another instance must Client::take_over.

A delegate (Client::delegate) is the same handle acting under another client’s lease (D33): it renews nothing, and is lost when its identity is fenced or the holder no longer lists it.

pub async fn detach(&self) -> Result<(), ClientError>

Gives the lease up; I/O through this handle fails from now on. The holder’s delegates are fenced first (D151): none of them writes after the lease is gone. A delegate’s handle just stops.

Source

pub async fn add_delegate(&self) -> Result<u64, ClientError>

Adds a delegate (D33, D151): an identity that acts under this lease. Returns it: whoever is given it opens the volume with Client::delegate. Delegates renew nothing, and are fenced with the holder.

Source

pub async fn remove_delegate(&self, d: u64) -> Result<(), ClientError>

Removes delegate d: fences it first (its requests are refused from then on), then takes it off the list.
