The client library (spec/volumes.md §10.1).

A Client holds the cluster map and connections to storage reactors. Volume I/O is split at chunk boundaries; each piece goes to its PG’s primary, all pieces in parallel. A StaleMap or NotPrimary answer, or a broken connection, refreshes the map and retries.
