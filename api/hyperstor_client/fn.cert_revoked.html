Gives this process its identity on the data path (D25, D373): every Client made afterwards starts TLS with it where the peer does, from its first connection. Set once, at start, by a service that was given one (--identity DIR); a second call changes nothing. Whether map has revoked the certificate a handshake showed (D384; 30-data-path-tls.md §33.5).
